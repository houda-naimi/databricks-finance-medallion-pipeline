# databricks-finance-medallion-pipeline
An end-to-end data engineering project in the finance domain built on Databricks. It implements a metadata-driven Medallion Architecture (Bronze, Silver, Gold) to process banking data from CSV files delivering a unified analytics platform with dashboards  for business insights.

This project implements an end-to-end data pipeline using Databricks.
